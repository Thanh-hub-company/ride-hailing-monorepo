3. CẤU HÌNH HEADER XÁC THỰC (Bắt buộc cho các API bảo mật)
--------------------------------------------------------------------------------
- Type : Bearer Token
- Key  : Authorization
- Value: Bearer <access_token_nhan_duoc_khi_dang_nhap>

4. JSON BODY MẪU (Postman / Body -> raw -> JSON)
--------------------------------------------------------------------------------

[A] Form Đăng nhập (Hỗ trợ cả Email, Số điện thoại hoặc identifier):
---------------------------------------------
Cách 1: Đăng nhập bằng Email:
{
  "email": "customer1@example.com",
  "password": "Password123!"
}

Cách 2: Đăng nhập bằng Số điện thoại:
{
  "phoneNumber": "0901234567",
  "password": "Password123!"
}

Cách 3: Đăng nhập bằng trường chung identifier:
{
  "identifier": "customer1@example.com",
  "password": "Password123!"
}

[B] Form Đăng ký tài khoản mới:
---------------------------------------------
{
  "email": "khachmoi@example.com",
  "phoneNumber": "0912345678",
  "password": "Password123!",
  "fullName": "Nguyen Van Moi",
  "role": "CUSTOMER"
}
*(role có thể là CUSTOMER hoặc DRIVER. Nếu là DRIVER, có thể bổ sung vehicleLicensePlate và vehicleModel)*

5. SCRIPT LƯU TOKEN TỰ ĐỘNG (Dán vào tab 'Tests' của request Đăng nhập trong Postman)
--------------------------------------------------------------------------------
if (pm.response.code === 200) {
    var response = pm.response.json();
    var token = response.accessToken || (response.data && response.data.accessToken);
    if (token) {
        pm.globals.set("token", token);
        console.log("✅ Token đã được lưu tự động vào biến toàn cục: " + token);
    }
}
